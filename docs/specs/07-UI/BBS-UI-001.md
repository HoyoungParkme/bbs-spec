## 2. 화면 목록

#### UI-1 글 목록

공지 묶음이 위, 일반 묶음이 아래. 각 행은 제목·글쓴이·작성일·댓글 수. 위에 검색창, 오른쪽에 `글쓰기`.
비로그인이면 `글쓰기` 대신 `로그인`. 근거: [[BBS-PRD-001#R1]] · [[BBS-PRD-001#R5]]

#### UI-2 글 본문

제목·글쓴이·작성일(`(수정됨)`)·본문, 그 아래 댓글 목록과 댓글창. 글쓴이 본인이면 `고치기`·`지우기`가 보인다.
근거: [[BBS-PRD-001#R3]] · [[BBS-PRD-001#R4]]

#### UI-3 글 쓰기·고치기

제목 한 줄, 본문 여러 줄, 운영자면 `공지로 올림` 체크. 아래 `저장`·`취소`. 쓰기와 고치기가 같은 화면이다.
근거: [[BBS-PRD-001#R2]]

#### UI-4 신고 다이얼로그

사유 셋(광고·욕설·기타) 중 하나를 고르고 `신고`. 이미 신고했으면 뜨지 않고 안내만.
근거: [[BBS-PRD-001#R6]]

#### UI-5 신고 처리

운영자만. 미처리 신고가 행으로. 각 행에 대상 글 미리보기와 `숨김`·`무시`.
근거: [[BBS-UC-001#UC-A7]]

#### UI-6 로그인

카카오 버튼 하나. 근거: [[BBS-INFRA-001#C3]]

## 3. 공통 틀

- 상단 바: 동아리 이름(홈) · 검색 · 내 이름 또는 `로그인`
- **글씨 최소 16px.** 오십 대 회원이 쓴다. 근거: [[BBS-SCN-001#P1]]
- 모바일에서 한 단, PC에서 가운데 정렬 800px
- 버튼은 높이 44px 이상 — 손가락으로 누른다
